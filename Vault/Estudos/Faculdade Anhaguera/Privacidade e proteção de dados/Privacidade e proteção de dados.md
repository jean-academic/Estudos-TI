## Conteúdo da aula

### Privacidade
Privacidade é o direito do indivíduo à vida privada, intimidade e controle sobre suas informações pessoais.

---

### Proteção de dados
Proteção de dados envolve medidas técnicas e organizacionais para proteger informações pessoais contra acesso indevido, vazamentos e uso inadequado.

Inclui:
- políticas de segurança
- controles de acesso
- criptografia
- governança de dados

---

### LGPD
A Lei Geral de Proteção de Dados regula o tratamento de dados pessoais no Brasil, protegendo direitos fundamentais de liberdade e privacidade.

A lei define:
- direitos dos titulares
- responsabilidades das empresas
- regras para tratamento de dados

---

### Dados pessoais
Qualquer informação que identifique uma pessoa.

Exemplos:
- nome
- CPF
- e-mail
- telefone

---

### Dados pessoais sensíveis
Dados que exigem maior proteção, como:
- saúde
- biometria
- religião
- opinião política
- origem racial

---

### Tratamento de dados
Qualquer operação feita com dados pessoais:

- coleta
- armazenamento
- acesso
- compartilhamento
- processamento
- eliminação

Representa o ciclo de vida da informação.

---

### Bases legais
Justificativas legais para tratamento de dados:

- consentimento
- obrigação legal
- execução de contrato
- legítimo interesse
- proteção da vida
- prevenção à fraude

---

### Cultura de proteção de dados
Proteção de dados não depende apenas de tecnologia.
Envolve pessoas, processos e governança.

Empresas precisam desenvolver uma cultura organizacional de proteção de dados.

---

## Resumo rápido
A LGPD regula o tratamento de dados pessoais e protege a privacidade dos indivíduos.  
A proteção de dados envolve controles técnicos e governança organizacional.  
Dados sensíveis exigem maior nível de segurança.  
Toda operação com dados pessoais precisa de uma base legal.
