Dados são representações de informações que podem ser coletadas, armazenadas, processadas e utilizadas por sistemas ou organizações.

Podem existir em diferentes formatos:
- texto
- números
- imagens
- registros digitais
- documentos
- logs

Dados são a base de sistemas de informação, análises e processos organizacionais.

---

## Tipos de dados (LGPD)

### Dados pessoais
Informações que identificam ou podem identificar uma pessoa.

Exemplos:
- nome
- CPF
- e-mail
- telefone
- endereço
- IP

---

### Dados sensíveis
Informações pessoais que exigem maior proteção.

Exemplos:
- saúde
- biometria
- religião
- opinião política

Relaciona-se com:
[[Dados sensiveis]]

---

### Dados anonimizados
Dados que não permitem identificar o titular.

---

## Ciclo de vida dos dados
Os dados passam por etapas como:
- coleta
- armazenamento
- processamento
- compartilhamento
- arquivamento
- destruição

Relaciona-se com:
[[Ciclo de vida dos dados]]

---

## Importância
Dados são ativos valiosos para organizações e precisam ser protegidos contra:
- vazamentos
- acessos não autorizados
- alterações indevidas
