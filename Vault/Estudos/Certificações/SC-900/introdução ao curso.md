# Introdução ao curso SC-900

## Objetivo
Compreender a estrutura da certificação SC-900 e os principais conceitos de segurança, conformidade e identidade no ecossistema Microsoft.

---

# Estrutura do exame SC-900

A certificação SC-900 é baseada em três pilares principais:

- Segurança
- Conformidade
- Identidade

O objetivo não é implementar serviços, mas compreender conceitos e funcionalidades.

---

# Segurança no Azure

Serviços fundamentais incluem:

- Network Security Group (ACLs)
- Azure Firewall
- WAF
- Azure Bastion
- DDoS Protection
- Key Vault
- Microsoft Defender for Cloud
- Microsoft Defender XDR

Esses serviços protegem:
- redes
- aplicações
- identidades
- dados
- infraestrutura

---

# Gestão de postura de segurança (CSPM)
Cloud Security Posture Management monitora a segurança da infraestrutura na cloud e fornece pontuações de segurança.

Relaciona-se com:
Microsoft Defender for Cloud.

---

# Conformidade no Microsoft 365

Ferramentas incluem:

- Microsoft Purview
- Data Loss Prevention (DLP)
- políticas de retenção
- eDiscovery
- auditoria
- gestão de registos

Essas ferramentas ajudam organizações a cumprir requisitos legais e regulatórios.

---

# Identidade

Principais serviços:

- Microsoft Entra ID (antigo Azure AD)
- Active Directory (on-premises)
- Windows Hello
- Privileged Identity Management

O Entra ID pode funcionar:
- sozinho na cloud
- integrado ao Active Directory local

---

# Conceito importante — Zero Trust

Zero Trust significa:
"nunca confiar automaticamente, sempre verificar".

Baseia-se em:
- identidade
- dispositivo
- contexto
- acesso mínimo necessário
