# Conteúdo da aula

## Ciclo de vida dos dados
O ciclo de vida dos dados representa todas as etapas pelas quais os dados pessoais passam dentro de uma organização.

Etapas:
- criação
- armazenamento
- uso
- compartilhamento
- arquivamento
- destruição

A responsabilidade da empresa começa no momento da coleta e termina apenas quando os dados são eliminados de forma segura.

Esse conceito é fundamental para identificar pontos de risco e vazamento de dados.

---

## Mapeamento de dados
Mapear dados significa identificar:

- onde os dados são coletados
- onde são armazenados
- quem acessa
- quais sistemas utilizam
- como são compartilhados

Isso permite aplicar controles de segurança adequados ao longo do fluxo de dados.

---

## Estados dos dados
Os dados podem existir em três estados:

Data in Motion → transmissão  
Data in Use → processamento  
Data at Rest → armazenamento  

Cada estado exige controles de segurança específicos.

---

## Tratamento de dados pessoais
Tratamento de dados inclui qualquer operação com dados pessoais, como:

- coleta
- armazenamento
- acesso
- compartilhamento
- processamento
- eliminação

Toda operação deve respeitar a LGPD.

---

# Princípios da LGPD

A LGPD estabelece princípios que orientam o tratamento de dados.

## Finalidade
Os dados devem ser coletados para um propósito específico.

## Adequação
O uso dos dados deve ser compatível com a finalidade informada.

## Necessidade
Deve-se coletar apenas os dados essenciais.

## Livre acesso
O titular pode acessar seus dados.

## Qualidade dos dados
Os dados devem ser corretos e atualizados.

## Transparência
A organização deve informar como os dados são usados.

## Segurança
Os dados devem ser protegidos contra acessos não autorizados.

## Prevenção
Medidas devem ser tomadas para evitar danos.

## Não discriminação
Os dados não podem ser usados de forma abusiva.

## Responsabilização
A organização deve demonstrar conformidade com a LGPD.

---

# Direitos do titular dos dados

A LGPD garante direitos ao titular, como:

- confirmação do tratamento
- acesso aos dados
- correção de dados
- anonimização
- portabilidade
- eliminação dos dados
- revogação do consentimento
- informação sobre compartilhamento

Esses direitos reforçam o controle do indivíduo sobre suas informações.

---

## Cookies e leads
Cookies armazenam informações no navegador do usuário.

Podem ser:
- funcionais
- analíticos
- comportamentais
- promocionais

Leads representam dados pessoais coletados em formulários e sistemas.

Ambos devem respeitar a LGPD, exigindo transparência e consentimento.

---

## Governança e proteção de dados
A adequação à LGPD depende de:

- políticas organizacionais
- controles técnicos
- treinamento de pessoas
- processos de segurança
- gestão de riscos

Proteção de dados é uma prática de governança, não apenas tecnologia.

## Aula 4 — Princípios Essenciais de Segurança na Era Digital

A proteção de dados na era digital depende de princípios fundamentais da segurança da informação.

Esses princípios garantem que dados e sistemas sejam protegidos durante todo o ciclo de vida da informação.

### Confidencialidade
Garantir que apenas pessoas autorizadas tenham acesso aos dados.

Exemplos:
- autenticação
- criptografia
- controle de acesso

Relaciona-se com:
[[Segurança da informação]]

---

### Integridade
Garantir que os dados não sejam alterados indevidamente.

Exemplos:
- hash
- controle de versão
- validação de dados

---

### Disponibilidade
Garantir que sistemas e dados estejam acessíveis quando necessário.

Exemplos:
- backups
- redundância
- monitoramento
- planos de recuperação

---

## Segurança na era digital
Com a digitalização de serviços e dados, a proteção da informação passou a depender de:

- infraestrutura de TI
- redes seguras
- políticas organizacionais
- conscientização de usuários
- gestão de riscos

A segurança da informação é a base técnica que permite o cumprimento da LGPD.

---

## Relação com LGPD
A LGPD depende diretamente da segurança da informação para proteger dados pessoais.

Sem controles técnicos de segurança, não é possível garantir:
- privacidade
- proteção de dados
- conformidade legal
