Identidade digital representa um usuário, sistema ou dispositivo dentro de um ambiente de TI.

Ela é usada para:
- autenticação
- autorização
- auditoria
- controle de acesso

---

## Exemplos
- contas de usuário
- contas administrativas
- serviços
- dispositivos
- aplicações

---

## Sistemas de identidade
- Active Directory
- Microsoft Entra ID
- IAM (Identity and Access Management)

---

## Importância
A identidade é o principal alvo de ataques modernos, pois controlar uma identidade permite acessar sistemas e dados.
